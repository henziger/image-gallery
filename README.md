# henziger.se - An image gallery web app

This web app was originally created from the [Next.js example with Cloudinary from Vercel](https://github.com/vercel/next.js/tree/canary/examples/with-cloudinary).
In a later upgrade, Cloudinary was dropped and the app now resembles the [Next.js example with Vercel Blob](https://github.com/vercel/next.js/tree/canary/examples/with-vercel-blob) with some additional fixes:

- Each image has a title and description, which can be seen if clicking the info (i) button.
- Image metadata is generated by running [./image-management/generate-upload-metadata.mjs](./image-management/generate-upload-metadata.mjs) and is written to [./image-management/upload-files.json](./image-management/upload-files.json)
- Compared to the Vercel example, [./utils/cachedImages.ts](./utils/cachedImages.ts) uses the metadata in upload-files.json instead of fetching the images from Vercel blob on each page load.

## Making your own image gallery

Execute [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app) with [pnpm](https://pnpm.io) to bootstrap the example:

```bash
pnpm create next-app --example with-vercel-blob with-vercel-blob-app
```

### Setup

1. [Create a Vercel Blob store](https://vercel.com/docs/storage/vercel-blob) and upload your images to its root.
2. Set `BLOB_STORE_ID` and `BLOB_READ_WRITE_TOKEN` in `.env.local` to the store's id and read/write token, respectively. You may also use `vercel env pull` to achieve this automatically.
3. `pnpm install`
4. `pnpm run dev`
